XSD Ontology: Description back to ToC

An OWL vocabulary formalizing XML Schema (XSD) 1.1's own abstract Schema Component Model (element/attribute declarations, simple/complex type definitions, particles, model groups) as graph-expressible classes and properties. Domain-agnostic: no relationship to any specific schema, module, or the Institutional Ontology's own concepts -- see the `realizations` repo for that linking layer. Ordering (xs:sequence) is expressed via an explicit xsdo:particlePosition integer property rather than rdf:List, deliberately -- see this repo's README for why.
