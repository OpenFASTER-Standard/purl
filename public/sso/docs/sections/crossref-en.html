A single addressable cell within a Sheet. No structural role (header, data) is assumed of any Cell by default.

Data Columnc back to ToC or Class ToC

IRI: https://purl.openfaster.org/sso/DataColumn

A vertical strip of cells holding one field's worth of data. Says nothing about which field -- that link is asserted separately, outside this vocabulary, via ofr:realizesConcept.
is in domain of
column index dp, data end row dp, data start row dp, header cell op, header matches dp, sheet op

Header Cellc back to ToC or Class ToC

IRI: https://purl.openfaster.org/sso/HeaderCell

A Cell playing the header role for a DataColumn. Asserted only where a header is actually known to exist -- never assumed.

column indexdp back to ToC or Data Property ToC

IRI: https://purl.openfaster.org/sso/columnIndex

1-based column position, matching Excel's own convention. Used on both Cell (its actual position) and DataColumn (a positional layout's fixed target column).
has domain
Cell c or Data Column c
has range
positive Integer
