Spreadsheet Ontology: Description back to ToC

An OWL vocabulary for spreadsheet structure. A raw, structure-agnostic Workbook/Sheet/Cell grid (no header or column meaning assumed) plus a separate, still domain-agnostic semantic layout layer (HeaderCell/DataColumn) for describing structure only where it is actually known. Concept-linking is not part of this vocabulary -- see the `realizations` repo's ofr:realizesConcept for that.
