purl.openfaster.org

Persistent-URL redirect service for OpenFASTER's ontologies and vocabularies — identifiers stay stable here even when the underlying files move. See OpenFASTER-Standard/purl for how this works.

Namespaces

/io/ — Institutional Ontology

URLResolves to
/io/IO_0000001 A term (All given names) — its entry on the browsable docs page
/io/IO_0000002 Another term (Last name) — same docs page, different anchor
/io/institutional-ontology.owl The whole ontology, OWL/RDF — pinned to the current tagged release, never main
/io The bare namespace — the ontology's source repo on GitHub
/io/docs/ Full browsable documentation for every term (generated by WIDOCO)
